4. KEY ARCHITECTURAL CHANGES:
- Blocking Evidence Retention: Rather than discarding which blocking channel generated a candidate, ProductionBlockingEngine retains exact channel bitflags for every pair, directly populating downstream feature columns and ranking weights.
- Candidate Safety Cap: Enforces max_candidates_per_s1 by ranking overflowing candidates via multi-factor evidence score (exact match, key count, shared ngrams, token pairs) instead of random truncation.
- Entity-Level Isolation: Guarantees that all candidate pairs for any given Source 1 entity ID remain exclusively within either the training split or the validation split.
- Hard Negative Sampling: Prioritizes challenging non-matches surviving multi-key blocking, computing dynamic scale_pos_weight to balance learning.
- Transductive Unlabeled TF-IDF: Fits vocabulary on the union of raw train and test text across all sources to eliminate out-of-vocabulary drift across country partitions (e.g. France).
- Configuration Fingerprint: An MD5 hash of all operational parameters verifies pipeline consistency between training and test inference.
